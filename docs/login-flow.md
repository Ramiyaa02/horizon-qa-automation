## Purpose

Per the assignment constraints, no login selectors, assertions, or success-path
tests are written until the actual authentication flow has been observed in the
browser. This file documents:

1. The navigation path to the login form
2. The actual form structure (fields, labels, placeholders, accessible roles)
3. Locators chosen and why (prefer role / label / placeholder / test IDs)
4. Observable success behavior (what changes in the DOM/URL after login)
5. Observable failure behavior (error messages/roles for invalid credentials)
6. Any authentication mechanics observed (redirects, tokens, storage keys)
